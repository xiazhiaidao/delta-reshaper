# 1.3.0 变更说明

- 版本：`delta-reshaper-1.3.0-original-forge-1.20.1.jar`
- 环境：Minecraft 1.20.1 / Forge 47.4.13 / TaCZ 1.1.8 / LR Tactical 0.4.3
- 物品 ID 不变：`delta_reshaper:reshaper`
- 与 1.2.x 的 mod ID 相同，**同一时间只能启用一个 JAR**

## 模型

由方块重建改为原始蒙皮三角形网格：源网格 10,213 顶点、12,896 三角形。按材质划分后只保留每个区域实际引用的顶点，不做三角简化，保留转刀枢轴与原始 UV。

## 动作

共 16 个运行时动作：两种拔刀、三段攻击、完整 13.6667 秒检视、3.6667 秒武器待机、2.1333 秒奔跑，以及移动与过渡轨道。

镜头、身体与武器轨道按源骨架配对，四元数采样保留原始转刀旋转。转刀与检视按原始指尖位置适配方块手末端，平滑进入与退出，刀和手腕旋转保持原样。

修复疾跑残留的距离跳进度：修复前实测约 3.79 倍速，修复后 1.0005 倍；实测循环 2.137 秒，源时长 2.133 秒。跳跃保持姿势与停止过渡保留。

## 音效

9 个事件、42 个音频变体，按动画通知时点播放。检视流式播放；打断或资源重载时停止所属音效。命中反馈沿用旧版。

## 渲染

- 普通渲染使用原始颜色与 ORM 做环境反射，握柄区域不反射环境。
- 光影下使用标准实体渲染与 LabPBR；基础选项关闭附加 PBR 与发光叠层。
- 检视青色表面光按原始 UV 重新适配。
- 补上原始法线图，金属区域降低漫反射，按粗糙度与拉丝方向计算高光，解决塑料感。
- 源网格直接渲染，渲染缓冲复用，去掉每个方块六面的开销。

## 重载

重载替换显示资源后，按 LR 原生初始化语义恢复上下文，不需要重新装备武器才能恢复动作。

## 验证

最终 JAR 完成原生游戏验收，22 项检查通过，覆盖三段攻击、服务器伤害、完整检视、音效打断、持续疾跑与无需重新装备的资源重载。

最终包疾跑时钟实测约 1.0007 倍速，循环约 2.125 秒；采样中未出现循环回绕之外的动画时间回跳。Photon v1.3b 与 Complementary Reimagined r5.9.3 均实测刀身、双手显示、基础/PBR 模式与检视青光。

## 未包含

原作程序材质与运行时材质曲线没有完整复现；当前保留几何，屏幕部分默认透明，反射、检视青光与 LabPBR 是面向 Minecraft 的适配实现。第三人称人物动作未转接。
